# Style DNA (rewritten)

Core look: Kangra / Punjab-school miniature in opaque gouache on handmade cotton paper, built as paper-theatre cut-out planes.
Material: matte pigment, visible brush strokes, slight paper tooth, flat layered shapes, soft edge outlines in darker pigment.
Structural rule: every plane is one object or one backdrop; light is flat and warm; shading by darker pigment bands, never gradients or glows.
Colour: mustard #E3A82B, vermilion #C23B22, phulkari magenta #B0225B, parrot green #3E7C3A, cream #F4E6C6, terracotta #B5573A, gold #C9972B, night indigo #1E2A5A. Time of day is graded in CSS, not repainted.
Cut-outs: flat #0057FF background, no blue inside the subject.

Reject: glossy/3D/plastic, bloom/lens flare, text or numerals in art, figures/faces/hands, sacred imagery (Guru Granth Sahib, Gurus, deities, khanda, palki), Rajasthani/Mughal palace, saffron as main colour, planes that disagree on light direction, marigold as wallpaper, phulkari as clip-art texture.
