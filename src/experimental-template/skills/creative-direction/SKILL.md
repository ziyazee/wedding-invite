# Creative Direction Skill

Methodology for establishing the visual identity of a wedding invitation template.

## Creative Brief Components

### 1. Concept Statement
One paragraph capturing the overall creative vision. Not vague ("elegant and beautiful") but specific ("the intimacy of a Kerala backwater ceremony at golden hour, where brass temple lamps reflect off still water").

### 2. Emotional Direction
- Primary emotion (joy, intimacy, grandeur, celebration, serenity)
- Emotional arc through the scroll journey
- What the guest should FEEL, not just see

### 3. Visual Identity
- Core metaphor or visual theme
- Key visual elements that define this template
- What makes this different from every other wedding invitation

### 4. Color System
Define as CSS custom properties:
- `--{prefix}-bg-primary`: main background
- `--{prefix}-bg-secondary`: alternate background
- `--{prefix}-text-primary`: main text
- `--{prefix}-text-secondary`: secondary text
- `--{prefix}-accent`: primary accent (often gold/metallic)
- `--{prefix}-accent-secondary`: secondary accent
- `--{prefix}-highlight`: call-to-action elements
- Each color needs a purpose, not just a name

### 5. Typography System
- Display font (couple names): family, weight, size range
- Heading font (section titles): family, weight, size range
- Body font (details, paragraphs): family, weight, size range
- Script/accent font (if applicable): family, usage
- All from Google Fonts unless user provides custom fonts

### 6. Materials & Textures
- What material does this invitation feel like? (silk, handmade paper, brass, marble)
- Background treatments (not flat color — texture, gradient, pattern overlay)
- Border treatments
- Shadow and depth language

### 7. Decorative Language
- Ornament style (intricate, minimal, geometric, organic)
- Divider/separator approach
- Frame style
- Pattern density and opacity

### 8. Section Flow
- How sections connect visually
- Shared elements that carry through
- Variation strategy (each section distinct but unified)

## Design Bible Structure

The `planning/design-bible.md` must have:
1. Concept statement
2. Color tokens (CSS custom properties with hex values)
3. Typography specifications
4. Spacing scale
5. Background treatments per section
6. Decorative elements catalog
7. Cultural elements usage
8. Responsive strategy
9. What this template is NOT (anti-patterns to avoid)

## Section Blueprints Structure

The `planning/section-blueprints.md` must have for each section:
1. Layout diagram (ASCII or description)
2. Content elements and hierarchy
3. Background treatment
4. Decorative elements
5. Typography assignments
6. Color usage
7. Spacing
8. Mobile adaptation
