# Reference Analysis Skill

Detailed methodology for analyzing wedding invitation reference material.

## Image Analysis Checklist

For each reference image, extract:

### Composition
- Overall layout structure (vertical, grid, layered, split)
- Visual hierarchy (what draws the eye first, second, third)
- Proportions and spacing between elements
- Negative space usage
- Content alignment (centered, asymmetric, edge-to-edge)

### Colors
- Extract specific hex values for: primary, secondary, accent, background, text
- Color temperature (warm/cool)
- Saturation range
- Contrast ratio between text and background
- Gradient directions and stops

### Typography
- Font identification or closest Google Font match
- Size hierarchy (display, heading, body, caption)
- Weight usage
- Letter-spacing and line-height estimates
- Script/calligraphic fonts used

### Decorative Elements
- Floral types and arrangements
- Ornamental patterns and motifs
- Borders and frames
- Geometric vs organic shapes
- Level of detail (minimal, moderate, intricate)

### Materials & Textures
- Paper, fabric, metal references
- Surface treatments (embossed, foiled, watercolor, digital)
- Transparency and overlay effects
- Depth and shadow cues

### Cultural Markers
- Specific to which tradition
- Historical vs modern interpretation
- Symbolic elements

## Video Analysis Checklist

For each reference video:
- Total duration
- Scene breakdown with timestamps
- Opening sequence (first 3 seconds)
- Camera/view movement (zoom, pan, parallax)
- Object movement (floating, swaying, flying)
- Transition types between scenes
- Typography animation style
- Background motion
- Loop behavior
- Audio cues (if relevant to timing)

Inspect frames at: 0%, 10%, 25%, 50%, 75%, 90%, 100% of duration minimum.

## Output Format

`planning/reference-analysis.md` with numbered sections, specific values (hex, px, percentages), and clear SEEN vs INFERRED distinction.
