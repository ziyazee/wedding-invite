Caching Strategy

Configured in vercel.json. Vercel edge serves these headers on every response.

365 days
immutable
Vite-hashed JS & CSS bundles, /assets/*, fonts (woff2/woff/ttf). Content-addressed filenames — never stale.
30 days
public, max-age
Images (png, jpg, webp, svg), video (mp4, mov), audio (mp3). Template assets with stable filenames.

Repeat visits: A guest revisiting after 30 days may re-download images/video/audio. Within 30 days, the browser serves from disk cache with zero network. Vite bundles never expire.

Edge caching: Vercel's edge CDN also caches these assets at PoPs worldwide. First guest in a region pays the origin fetch; subsequent guests in that region get edge-cached responses.

Not cached: HTML pages (index.html) are always fetched fresh to pick up template personalization. The get_published_invitation RPC call is also uncached (needs invalidation strategy).

MangalEach scene has a data-tint attribute ("warm" or "cool") — CSS applies a solid color tint matching the scene's palette while the background WebP loads. If WebP fails, applyImage() adds is-ready is-missing classes and the tint remains as the permanent background. Before optimization: desktop viewers saw tint-only because landscape PNGs didn't exist (404). Now fixed with WebP conversions.

Embroidered GardenCSS fallback in interactions.css: if intro video errors, #opening:has(.video-unavailable) shows the hero WebP as a background (updated from 3 MB PNG to 302 KB WebP).
